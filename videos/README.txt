Put video files for the Help page here (for example first-election.mp4), then add a line  file: "videos/first-election.mp4"
to that video's entry in js/tutorials-data.js.

Tips
- Use .mp4 (H.264 video, AAC sound): it plays in every browser.
- Free hosting (GitHub Pages) allows files up to 100 MB, and the whole site should stay under about 1 GB. For long or large videos, upload to
  YouTube as "Unlisted" instead and use  youtube: "THE_CODE"  (the page then loads the video only when someone presses play).
- Add subtitles if you can: a .vtt file and  captions: "videos/first-election.vtt"  (YouTube makes its own).
